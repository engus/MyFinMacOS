# Execution core

- Resolve the smallest owning scope before broad inspection. Gather independent, bounded facts together when practical.
- Measure unknown input size when cheap. Bound large inspection first, but never truncate content that must be understood as a whole.
- Prefer formal contracts or templates; otherwise inspect two examples of the exact construct being changed.
- Probe task-required environment dependencies together. Repair only local, reversible, in-scope environment gaps.
- Run explicit task checks and affected validators/tests. Stop once required verification is green and no concrete risk remains.
- After a second materially identical failure, use a different root-cause hypothesis and a materially different action.
- Poll only when it can produce new information; blocking commands need no artificial polling.
